# Security policy

## Supported versions

Only the current `main` branch is supported. The live site is built and
deployed from it.

## Reporting a vulnerability

Please report security issues privately by email to
[nathan@nixoncreativestudio.com](mailto:nathan@nixoncreativestudio.com).
Do not open a public issue or pull request for a suspected vulnerability.

Include what you found, how to reproduce it, and any impact you can see. You
will get an acknowledgement, and a fix will land on `main` once confirmed.
